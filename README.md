# VPD 해석 업무 협업 대시보드 — Admin 별도 창 버전

## 화면 구성
- `index.html`: 일반 사용자 화면 / 현황 / 해석 업무 신청
- `admin.html`: 관리자 전용 별도 페이지 / 비밀번호 1111(시연용) / 승인·상태·진행률·담당자 관리
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `og-index.png`: 브랜드 이미지

## 실행 (추천)
압축 해제한 VPD_dashboard 폴더 안에서 터미널 실행:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/index.html` 접속.
상단의 **Admin ↗** 버튼을 누르면 `admin.html`이 **새 탭**으로 열립니다.

## 관리자 사용
1. 일반 화면에서 업무 신청 (소속, 직위, 성명, 해석 요청사항, 첨부파일)
2. 상단 Admin 버튼 -> 새 탭
3. 시연용 관리자 비밀번호 `1111` 입력
4. 신청 목록에서 `검토 / 변경`
5. 상태 `요청 → 검토대기 → 진행 → 완료 / 보류`, 담당자, 진행률, 의견 수정
6. 변경 후 메인 페이지로 돌아오면 데이터가 갱신됩니다 (다른 탭에서 수정하면 자동 반영되며, 필요 시 새로고침)

## 주의
- 이 파일은 **로컬 시연용**이며, 암호는 클라이언트 코드에 노출됩니다. 실제 인증 보안이 아닙니다.
- 신청정보는 `localStorage`, 첨부파일은 `IndexedDB`에 저장됩니다.
- 같은 브라우저·동일 웹 주소(Origin)에서만 데이터가 공유됩니다. 다른 PC와는 자동 동기화되지 않습니다.
- 파일을 직접 더블클릭한 `file://` 실행에서는 브라우저에 따라 저장소 공유가 보장되지 않습니다.
- 실제 사내 업무용으로는 서버 인증, 권한 제어, 중앙 DB, 별도 첨부파일 저장소가 필요합니다.
- 사내 기밀 자료나 개인정보를 이 시연용 화면에 입력하지 마세요.
