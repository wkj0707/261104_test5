# VPD 업무 협업 대시보드

VPD = Virtual Product Development

## 구성
- 구조피로 해석 3명
- 소음진동 해석 2명
- 열유동해석 1명
- 총 6명

## 사용 방법
1. `index.html` 파일을 브라우저에서 엽니다.
2. `업무 등록`에서 해석 프로젝트를 추가합니다.
3. 업무 목록에서 수정 버튼을 누르면 상태, 진행률, 일정, 담당자 등을 수정할 수 있습니다.
4. `CSV 내보내기`로 업무 목록을 저장할 수 있습니다.
5. `협업 링크 설정`에서 승인된 사내 공유 폴더 / 회의록 / 일정 URL을 입력합니다.
6. `데이터 백업(JSON)` 및 `백업 복원`으로 다른 브라우저에 데이터를 옮길 수 있습니다.

## 데이터 및 보안 주의
이 버전은 별도의 서버 없이 작동하며, 데이터는 사용 브라우저의 localStorage에 저장됩니다.
사람 간 데이터 실시간 동기화 및 접근제어 기능은 제공되지 않습니다.
브라우저 데이터를 지우면 업무 기록도 사라질 수 있으니 JSON 백업을 활용하세요.
실제 회사 기밀/개인 정보 및 설계/시험 기밀 문서는 공개 GitHub Pages에 업로드하지 마세요.
배포 전 회사의 정보보안 정책과 승인된 내부 호스팅 환경을 확인하세요.
